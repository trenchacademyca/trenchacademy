# Media

Drop site assets in here.

- `hero/` — hero background image or video (e.g. `hero.mp4`, `hero-poster.jpg`)
- `gallery/` — photos for the Gallery page
- `coaches/` — coach portraits, referenced from `src/data/coaches.ts`
- `athletes/` — athlete photos, referenced from `src/data/athletes.ts`

Reference assets in code with paths relative to `/public`, e.g. `/media/hero/hero-poster.jpg`.
